一个免费、非商业的《地狱潜兵2》兼容包，让 Chef Shared Loader 与 MDL3 在
HD2 Mod Quick Deploy 下并行运行。

## 为什么

HD2 Mod Quick Deploy 一次只部署一个加载器。选定 MDL3 时，Chef Shared Loader 被
完全排除、根本无法启动，F9 选项菜单和所有 Chef 模组都不可用。本包让管理器把
Chef 当作普通模组，而 MDL3 仍是选定的加载器。

## 工作原理

- MDL3 保持**独立的加载器条目**，永远最后部署（最高补丁层，拥有启动脚本）。
- Chef 排在它下面；`Chef Hand-off for MDL3` 在游戏启动约 6 秒后拉起 Chef。
- 本包只贡献**两个补丁层**：Chef 核心与交接 addon。**不分发任何语言包**；想要
  翻译菜单的用户可自行安装 `-- HD2-Lang` 纯数据语言包，Chef 会自动合并同名语言。
- Chef 的核心资源被改名，管理器不再把它识别为加载器。
- 核心里一小段运行时兼容处理，用来修复 MDL3 在交接前抢先启动的模组留下的残状态。
- 仅普通 Lua：没有游戏逻辑代码、不碰反作弊；管理器只是增加补丁层，不修改游戏基础文件。

## 安装 / 更新

1. 添加本包，或对已有条目使用**替换**（保留加载顺序、启用状态和选项）。
2. 确认 MDL3 仍是选定的加载器。
3. 部署一次，然后从 Steam 启动游戏。按 F9 打开菜单，在模组名上按 → 展开设置。

发布文件（含校验值的压缩包）作为 GitHub Release 附件提供；该 zip 未提交进仓库主体。

## 范围与局限

- 本包仅适用于双加载器配置（Chef + MDL3 一起用）。
- 只想单用 Chef、不装 MDL3 的用户，请使用官方未修改版：Quick Deploy 通过硬编码的
  资源编号识别加载器，我们改名后的构建在该判定中是刻意「隐形」的，无法被选为加载器。
- 不要同时启用官方 Chef 条目与本包。
- 简体中文语言包可独立安装，两种配置都能单独使用。
